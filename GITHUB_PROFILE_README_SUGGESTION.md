## 🚀 Featured Project

### 🛡️ [LoanGuard AI — Loan Default Risk Prediction & Underwriting](https://github.com/sreeramganesh/loan-default-risk-prediction)

An end-to-end Machine Learning web application evaluating loan applicant risk to mitigate credit default losses.

- **Live Application:** [https://loan-default-risk-prediction-ro68.onrender.com](https://loan-default-risk-prediction-ro68.onrender.com)
- **Health Check:** [https://loan-default-risk-prediction-ro68.onrender.com/health](https://loan-default-risk-prediction-ro68.onrender.com/health)
- **Source Code:** [https://github.com/sreeramganesh/loan-default-risk-prediction](https://github.com/sreeramganesh/loan-default-risk-prediction)
- **Stack:** Python 3.11, Flask, Scikit-Learn, Random Forest, Gunicorn, Render, HTML5/CSS/JavaScript

**Core Highlights:**
- **Machine Learning Inference:** Random Forest Classifier trained on 38,574 historical loan records, achieving 20.10% defaulter recall (more than double the baseline Decision Tree).
- **Automated Underwriting:** Categorizes applicants into `VERIFIED & APPROVED`, `MANUAL UNDERWRITER REVIEW`, and `REJECTED (HIGH DEFAULT RISK)` tiers.
- **Dynamic Frontend:** Responsive dark-glassmorphism dashboard with real-time Debt-to-Income (DTI) and payment burden calculations.
- **Production Deployment:** Containerized on Render Free Web Service with Gunicorn WSGI.
